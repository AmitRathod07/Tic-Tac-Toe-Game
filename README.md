# 🎮 Tic-Tac-Toe Game

A modern, interactive, and responsive implementation of the classic Tic-Tac-Toe game, built with clean code and modern web technologies.

## ✨ Features

* **Interactive Gameplay:** Smooth and intuitive turn-based user interface for two players.
* **Winner Detection:** Automatically detects winning combinations, diagonals, and ties (draws).
* **Reset & Restart:** Easily clear the board to start a fresh match at any time.
* **Responsive Design:** Optimized to play seamlessly across desktops, tablets, and mobile devices.

## 🛠️ Tech Stack

* **Frontend:** HTML5, CSS3, JavaScript (or your specific framework if applicable)
* **Build Tool:** Vite

## 🚀 Getting Started Locally

To run this project on your local machine, follow these simple steps:

### 1. Clone the repository

```bash
git clone https://github.com/AmitRathod07/Tic-Tac-Toe-Game.git

```

### 2. Navigate to the project directory

```bash
cd Tic-Tac-Toe-Game

```

### 3. Install dependencies

```bash
npm install

```

### 4. Run the development server

```bash
npm run dev

```
